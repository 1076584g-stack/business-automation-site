# 設計上の判断

## 2026-11-18 CSV自動集計ツール紹介ページの改修

既存の単一HTML構成を使い、ネイビー・白・深緑で情報のまとまりと購入導線を示す。導入前後の違いは操作手順で表し、サンプル表には架空データの集計イメージと明記する。販促情報は旧ページと出品内容で確認できる範囲を使う。64ビット版の実機確認状況は対応環境とFAQに記載する。

公開URLをcanonicalとOGPに指定する。購入・相談はココナラへのリンクで案内する。
月次集計の担当者が作業を思い浮かべられる導入文を採用し、CSV統合・エラー確認・買い切りの3点を説明する。購入導線は既存のココナラ出品へつなぐ。

ShopifyのEC事例とUgmonkのAnalog商品ページを参照。最初の画面で商品がどう使われるかを示す構成を、架空のCSVファイル名と集計表で表現する。ネイビー・白・深緑を使い、購入ボタンの隣に対応環境への導線を置く。

集計イメージはHTML・CSS・JavaScriptで再現する。サンプルが画面に入ったときに一度だけ自動再生し、停止と再生を操作できる。動きを減らす設定の場合は集計例を初期表示し、手動再生時のカーソル移動を省略する。

デモの結果表は帳票を思わせる生成りの背景と罫線でまとめる。静止時にも集計例が読みやすいことを優先し、操作時の強調は選択色、カーソルの短い反応、細い進捗線に絞る。
